4. MemoryPool 하나의 안쪽 (128 풀)

5. Allocate와 Release 순서

Allocate(size)

  1. size 범위 검사 (0 이하, int32 넘침 → 크래시)
  2. blockSize = size + 16
  3. 4096 이하 → poolTable_[blockSize]->Pop()
    초과 → _aligned_malloc(blockSize, 16)
  4. AttachHeader: 헤더 생성, allocSize_ = blockSize
  5. header + 1 반환 (16 정렬)

Release(ptr)

  1. nullptr이면 아무것도 안 함
  2. DetachHeader: ptr − 16 = 헤더
  3. blockSize = allocSize_ (0이면 이중 해제 → 크래시)
  4. 4096 이하 → poolTable_[blockSize]->Push() (allocSize_ = 0)
    초과 → _aligned_free
